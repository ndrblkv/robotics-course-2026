# Ноды, топики, сообщения, паблишер и подписчик на примере turtlesim.
## Демонстрационная симуляционная среда turtlesim.
Для запуска в одном терминале запускается нода
```bash
ros2 run turtlesim turtlesim_node
```
и в другом терминале нода
```bash
ros2 run turtlesim turtle_teleop_key
```
Для просмотра топологии нод, топиков, сервисов и действий используется утилита
```bash
rqt_graph
```

## Ноды
Посмотреть список всех запущенных нод:
```bash
ros2 node list
```
С помощью подкоманды info можно получить подробную информацию о конкретном узле:
```bash
ros2 node info /turtlesim
```

## Топики
Посмотреть список всех существующих топиков:
```bash
ros2 topic list
```
Добавив подкоманду echo, можно показать данные сообщений в конкретном топике:
```bash
ros2 topic echo /turtle1/pose
```
Через терминал можно напрямую опубликовать сообщение в топике (--once - только один раз, --rate <частота> - сколько раз в секунду):
```bash
ros2 topic pub --rate 1 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 1.8}}"
```
Прослушать сообщения, приходящие в топик можно командой:
```bash
ros2 topic echo /turtle1/cmd_vel
```
Бывает полезно просматривать не все сообщение, а только отдельные поля (например, только линейную составляющую скорости). Для этого используйте опцию --field:
```bash
ros2 topic echo /cmd_vel --field linear
```
